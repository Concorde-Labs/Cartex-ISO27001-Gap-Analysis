# ISO/IEC 27001:2022 Gap Assessment | Cartex Technologies Ltd.

## Project Overview

This project presents a risk-informed information security gap assessment of Cartex Technologies Ltd., a technology organization operating a digital platform for sales, inventory management, customer information, and payment processing.

The assessment evaluates existing security practices against relevant ISO/IEC 27001:2022 requirements, identifies control weaknesses, and develops practical remediation recommendations to strengthen Information Security Management System (ISMS) readiness.

## Assessment Highlights

- **6 findings identified:** Five Annex A control gaps and one ISMS governance gap.
- **Control mapping:** Organizational, People, Physical, and Technological control categories.
- **Risk evaluation:** Potential security implications and preliminary remediation priorities.
- **Remediation planning:** Proposed accountable functions, implementation timelines, and corrective actions.
- **Audit readiness:** Expected evidence and verification methods for assessing remediation effectiveness.

## Framework and Controls

**Framework:** ISO/IEC 27001:2022

**Relevant Annex A Controls:**
- A.5.9 - Inventory of Information and Other Associated Assets
- A.6.3 - Information Security Awareness, Education and Training
- A.7.2 - Physical Entry
- A.5.18 - Access Rights
- A.8.5 - Secure Authentication

**Management System Requirement:** Clause 4.3 - Determining the Scope of the ISMS.
